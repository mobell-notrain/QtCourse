# Qt 课程实验二：简单文本编辑器（Lab2）

Qt 应用程序开发（2026 年秋季）实验二的作业工程。分支 `Lab2` 保存完整工程，以及按实验报告
“实验步骤及结果”12 个要点拆分的提交日志。

## 环境

- Windows 10 / 11 64 位（macOS、Linux 亦可）
- Qt Widgets（本地使用 Qt 6.12.0 MinGW 13.1 64-bit 构建，接口与 Qt 5.12 兼容）
- qmake + mingw32-make（或直接用 Qt Creator 打开 `Lab2/Lab2.pro`）

## 构建

```bash
cd Lab2
qmake Lab2.pro
mingw32-make
```

工具栏图标放在仓库根目录 `RES/`，由 `Lab2/res.qrc` 以 `../RES/*.png` 引用，
所以要保持 `Lab2/` 与 `RES/` 同级。

## 目录结构

```
.
├── Lab2/                主工程
│   ├── Lab2.pro
│   ├── main.cpp
│   ├── mainwindow.*     主窗口：菜单 / 工具栏 / 文件操作 / 状态栏
│   ├── AboutDialog.*    关于对话框
│   ├── SearchDialog.*   查找对话框
│   ├── replacedialog.*  替换对话框
│   ├── CodeEditor.*     带行号的编辑器（QPlainTextEdit 派生）
│   └── res.qrc          工具栏图标资源清单
├── RES/                 工具栏图标（png）
└── docs/Lab2-实验日志.md  按步骤拆分的实验日志
```
